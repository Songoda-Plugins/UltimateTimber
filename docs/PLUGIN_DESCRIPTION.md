## UltimateTimber: animated Minecraft tree felling

UltimateTimber is a Minecraft tree felling plugin that turns chopping a log into an animated falling tree. Configure tree detection, sapling replanting, tools, drops, and rewards to make woodcutting part of your survival server's progression.

## Choose how trees fall

Use a toppling, crumbling, or disintegrating animation, or remove the detected tree immediately. Tune sounds, particles, and falling-block damage. Tree definitions let you choose matching logs, branches, leaves, and saplings, with limits on the size of each chop.

## Control tools, drops, and regrowth

- Choose accepted tools, durability rules, cooldowns, worlds, and player permissions.
- Replant configured saplings on valid soil and tune falling-leaf replanting separately.
- Configure custom drops, bonus loot, and command rewards for logs, leaves, or whole trees.
- Let players toggle tree chopping to suit the task they are working on.

## Connect woodcutting to player progression

Track player chopping statistics, display PlaceholderAPI values, and create persistent leaderboard holograms. Optional integrations connect woodcutting to protection, skills, jobs, and quests, including WorldGuard, GriefPrevention, UltimateClaims, mcMMO, and Jobs Reborn. See the [compatibility guide](https://songoda-reborn.com/plugins/ultimatetimber/wiki/features/compatibility) for integration details.

## Fit tree chopping to your survival rules

Use UltimateTimber for a survival woodcutting area, a forestry progression system, or a server where players want to gather logs without breaking each one separately. The animation is only one part of the setup: tool durability, accepted tools, cooldowns, and rewards determine how generous each chop should be. A player toggle lets builders switch chopping off when they need to remove an individual log.

Tree definitions identify the blocks that belong together, rather than treating every connected log as a valid tree. Minimum leaf requirements and log limits help distinguish a tree from other structures. Player-placed block tracking can skip recently recorded placed blocks, but it is held in memory and does not replace a protection plugin or a permanent block history.

## Replanting and rewards are separate choices

Replanting can restore a configured sapling after a chop when the target location and soil are valid. Falling leaves have their own replanting option, so you can tune the visual effect and forest renewal independently. Replanting does not guarantee that a sapling can be placed in every location.

Keep ordinary wood drops, configure bonus loot, or use command rewards to connect chopping with your server's progression. For a first installation, test a natural tree with a vanilla axe, then change one rule at a time. If a tree does not fall, check its definition, leaves, world, accepted tool, chopping toggle, and protection rules before raising limits.

UltimateTimber supports Paper, Spigot, Purpur, and Folia from Minecraft 1.18.2. Check the [release history](https://songoda-reborn.com/plugins/ultimatetimber/versions) for the versions listed for your chosen release, then follow the [getting started guide](https://songoda-reborn.com/plugins/ultimatetimber/wiki/getting-started) to install and test your first tree.
