## Installation
To install Ultimate Timber you will need to:

1. Turn your server off.
2. Add the required dependencies: Vault.
3. Add the optional dependencies: mcMMO, Jobs.
4. Add in the latest version of Ultimate Timber which you can find in our marketplace.
5. Turn your server back on.

## Commands & Permissions

| Command | Description | Permission |
|---|---|---|
| `/ut` | Shows the plugin's information. | `Default` |
| `/ut reload` | Reloads the Configuration and Language files for UltimateTimber. | `ultimatetimber.reload` |
| `/ut toggle` | Toggles tree chopping. | `ultimatetimber.toggle` |

### Permissions

| Permission | Description | Default |
|---|---|---|
| `ultimatetimber.*` | Inherits all UltimateTimber permissions, including child permissions. | `op` |
| `ultimatetimber.chop` | Allows players to trigger the tree toppling effect. | `op` |
| `ultimatetimber.bonusloot` | Allows players to receive bonus loot from trees. | `op` |
| `ultimatetimber.reload` | Allows the player to reload the configuration file. | `op` |
| `ultimatetimber.bypasscooldown` | Allows a player to bypass the tree toppling cooldown. | `op` |
| `ultimatetimber.animation.<animation_type>` | Allows the player to use a specific tree animation type. | `op` |

## FAQ’s

**Q: How do I chop down trees with this plugin?**
A: Simply chop the bottom block of a tree and the entire tree will topple down with animation.

**Q: What is tree detection?**
A: The plugin accurately detects which blocks belong to a tree to ensure only the tree falls.

**Q: Can I configure custom drops?**
A: Yes, you can configure custom drop tables for different tree types.

**Q: What sounds are included?**
A: The plugin includes realistic wood cracking and falling sounds for immersion.

**Q: Does this work with mcMMO?**
A: Yes, UltimateTimber integrates with mcMMO for woodcutting XP and abilities.
